This file needs a dev server

You opened index.html straight from your folder. That can't work, and it isn't a bug — this file is a build source, not a finished page. It points at /src/main.jsx, and JSX has to be compiled before a browser can run it.

Want to just look at the site?

Double-click milo-portfolio-preview.html instead.
One self-contained file. No install, no server, images included.

Want to run the real app?

  1. Open a terminal in this folder
  2. Run the two commands below
  3. Visit the localhost address it prints
npm install
npm run dev

Publishing it

npm run deploy

That builds into dist/ and pushes to GitHub Pages. The contents of dist/ are the version that works when opened from a server — never this file.
